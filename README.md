## Описание

Браузерная игра «Мэй собирает жёлуди»: механика Game & Watch «Волк ловит яйца» в мире «Мой сосед Тоторо». Один HTML-файл, без сборки и внешних картинок. Открывается в Safari на iPhone.

## Содержимое

- `may-collect-an-acorn.html` — сама игра
- `requaments/` — механика игры и разбор оригинала «Волк ловит яйца»
- `openspec/` — спецификации изменений
- `screenshots/` — снимки экранов
- `.debug-server.py` — локальный сервер отладки
- `mempalace.yaml` — крыло MemPalace этого проекта
